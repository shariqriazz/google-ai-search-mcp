# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
`shariq@orchestriai.com`. Include the affected version, reproduction steps,
impact, and any suggested mitigation you have tested.

Do not open a public issue for an unpatched vulnerability or include API keys,
Google Cloud credentials, access tokens, or customer data in a report. Public
issues are appropriate for non-sensitive bugs and hardening suggestions.

I will acknowledge a security report within five business days and will share
the next assessment or remediation step after reproducing and triaging it.

## Supported versions

Security fixes are applied to the latest published version. Upgrade to the
current npm release before reporting an issue that may already be resolved.
